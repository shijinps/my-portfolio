Client Requirements & Solution Design

The client required an enterprise-grade infrastructure capable of delivering maximum throughput, zero single points of failure (SPOF), and high-density wireless coverage. After analyzing operational bandwidth and resilience requirements, we proposed and delivered an Arista Networks switching fabric coupled with enterprise perimeter security powered by Fortinet FortiGate.

Core Objectives
  • Eliminate all single points of failure across core and access layers
  • High-throughput 10G interconnects across campus distribution
  • Next-generation perimeter firewalling with stateful failover
  • Wi-Fi 7 readiness for high-density client access
Hardware Bill of Materials (BOM)
  • Arista 720DP Series Enterprise Switches (Core & Access)
  • Arista AP-C460 Wi-Fi 7 Enterprise Access Points
  • Dual Fortinet FortiGate 200G Next-Gen Firewalls
  • Arista SFP-10G-T-RP transceivers, DAC cables & OM3/OM4 fiber
02

Dual Core High Availability (HA) & Redundant Uplink Topology

To ensure total fault tolerance, the switching architecture was engineered with a dual-core topology:

  • Dual Core Switches: Two Arista switches operate as redundant core engines interconnecting via high-speed inter-switch links (ISL / MLAG) for synchronized state and seamless Layer 2/3 forwarding.
  • Dual-Homed Access Layer: 4 Access Switches and 2 AP Switches are connected to the core. Every single switch has dedicated redundant uplinks split between Core Switch 1 and Core Switch 2.
  • Fortinet FortiGate 200G HA Cluster: Configured in High Availability (Active-Passive with synchronized session tables) connected directly to both core switches with redundant trunk links.
  • Physical Cabling Matrix: RJ45 Cat6 patch leads for endpoint & PoE access, Direct Attach Copper (DAC) high-speed twinax cables for adjacent rack uplinks, and OM3/OM4 Duplex LC-LC Multimode Fiber for high-speed optical distribution.
03

Physical Staging, Console Provisioning & Bench Assembly

Prior to rack deployment in the server room, the entire hardware fleet was unboxed and staged in the lab environment for baseline provisioning:

Firmware & Base OS

Unboxed Arista 720DP switches and FortiGate 200Gs, connected via serial consoles, upgraded EOS/FortiOS to target enterprise gold-star releases, and verified cryptographic signatures.

VLANs & Link Aggregation

Configured management IP subnets, 802.1Q VLAN trunking, LACP multi-chassis link aggregation, Spanning Tree Protocol (RSTP/MSTP) priorities, and port security.

HA Cluster Synchronization

Paired the FortiGate 200G firewalls using dedicated heartbeat links, verified session state syncing, and confirmed active cluster health on the hardware status indicators.

04

Live Failover Stress Testing (Cable-Pull Phase)

The most crucial validation step in the bench staging was physically stress-testing the redundancy mechanisms:

Simulated Primary Link Failure: With active network traffic passing and sustained ICMP stream verification running across monitoring consoles (ping 8.8.8.8 -t), we systematically disconnected and removed each uplink cable connected to Core Switch 1.

Automatic Dynamic Rerouting: Traffic seamlessly traversed the secondary uplink to Core Switch 2 without packet drops, verifying instantaneous LACP failover and Spanning Tree convergence.

Firewall Heartbeat Disruption: Simulated primary firewall failure; the secondary FortiGate unit assumed active master state instantaneously with continuous stateful session retention.

Project Results & Engineering Highlights

Zero Packet Loss: Cable extraction stress tests produced zero drops during sustained ping verification, confirming robust MLAG / spanning-tree fast convergence.
Complete Redundancy: Dual-homed cabling across Core 1 and Core 2 guarantees that an entire core chassis failure causes zero network downtime for access switches or Wi-Fi APs.
Enterprise Security: Dual FortiGate 200Gs maintain real-time session synchronization, providing instantaneous stateful firewall failover.
Production Ready: Full documentation, cabling labeling scheme, and baseline configs delivered to the client for structured long-term administration.
